# 13期生 6410 卒業研究 資料
## このリポジトリについて
このリポジトリは、13期生 6410の卒業研究に付属する資料(ソースコード・データ)である。構造は以下に示すとおりである。
```
GThesis
|-KeyLayout
| |-Colemak.json
| |-Dvorak.json
| |-QWERTY.json
| |-QWERTZ.json
|
|-Text
| |-inputDE.txt
| |-inputEN.txt
| |-inputES.txt
| |-inputJP.txt(本文ではinputJAと呼称)
|
|-test3.py
|-test4.py
```
## 各ディレクトリ・ファイルについて
### KeyLayout/*
キー配列の定義ファイル(json)。構造は以下に示すとおりである。
```json
{
  "KeyLeyout":{
    "1":{"hand":"L", "finger":"1", "x":0.0, "y":0.0},
    "キーの文字":{
      "hand":"割り当てる手(L/R)",
      "finger":"割り当てる指(小指から人差し指へ1～4)",
      "x":"数値で、キーのx座標(右向き正)",
      "y":"数値で、キーのy座標(下向き正)"
      }
  },
  "HomePosition":{
    "L_1":"A",
    "(左右L/R)_(指1～4)":"指を置くキー"
  }
}
```
> [!important]
> `"KeyLayout"`ではなく`"KeyLeyout"`です。タイプミスをそのまま実装してしまったため、このようになっています。

### Text/*
シミュレーションする入力文字列。有効な文字は以下に示すとおりである。ただし、全て半角文字である。
- 大文字のアルファベット
- ピリオド
- カンマ
- ハイフン
- コロン
- 数字(扱ったデータには含まれない)
これ以外の文字は全て計算時にスキップされる。
### test3.py, test4.py
シミュレーションのためのプログラム。test4.pyの結果を本文に用いた。両者の違いは、移動距離の算出時に全てのキーをホームポジションからの距離で算出するか(test3.py)、同じ指で打鍵した最後のキーの位置からの距離で算出するか(test4.py)である。
